# Resume Generator Demo

This repository is a static, synthetic demonstration of the Resume Generator
output. Every person, company, vacancy, profile fact, and generated artifact is
fictional.

The runnable project is available at
[`snakeye/resume-generator`](https://github.com/snakeye/resume-generator).
This repository intentionally does not contain the local runner, GitHub Issue
Form, provider configuration, or credentials.

## Contents

- `data/profile/`: synthetic profile used for the example;
- `data/examples/vacancies/`: synthetic vacancy input;
- `data/output/`: generated JSON, Markdown, TeX, PDF, DOCX, report, and metadata.

The PDF and DOCX were rendered locally from the synthetic profile. No real
candidate data or live LLM response is included.
